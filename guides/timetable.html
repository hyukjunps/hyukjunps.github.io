내 시간표 설정하기

오풍 시간표는 학교에서 자동으로 내려받는 시간표가 아니라 사용자가 직접 작성하는 시간표입니다. 학교나 담임 선생님이 안내한 시간표를 준비한 뒤 입력하세요.

  1. 시간표 메뉴에서 사용할 교시 수를 정하고 적용합니다.
  2. 해당 요일과 교시에 과목을 입력합니다. 수정 내용은 현재 브라우저에 저장됩니다.
  3. 홈으로 돌아와 오늘의 시간표가 입력 내용과 맞는지 확인합니다. 시간표가 변경되면 해당 칸을 수정합니다.

저장되는 위치와 한계

시간표와 맞춤 설정은 이 기기의 브라우저 저장소를 사용합니다. 같은 주소를 열더라도 다른 브라우저, 다른 기기, 비공개 창에서는 기존 내용이 보이지 않을 수 있습니다. 브라우저 데이터를 삭제하면 저장한 내용도 함께 사라질 수 있습니다.

현재 입력값을 계정으로 동기화하거나 서버에서 복원하는 기능은 제공하지 않습니다. 초기화하거나 기기를 바꾸기 전에는 시간표를 캡처하거나 별도 메모로 옮겨 두세요.

앱처럼 빠르게 열기

지원되는 환경에서는 오풍의 앱 설치 버튼이나 브라우저 메뉴의 홈 화면 추가·앱 설치 항목으로 바로가기를 만들 수 있습니다. 메뉴 명칭과 설치 지원 여부는 운영체제와 브라우저에 따라 다릅니다.

별도 계정 없이 웹 주소로도 사용할 수 있습니다. 홈 화면에 추가했다고 급식·날씨 같은 실시간 자료까지 오프라인에서 제공되는 것은 아닙니다. 최신 정보 조회에는 네트워크가 필요합니다.

이름·위젯 설정과 시간표를 구분하세요

맞춤 설정에서 이름과 홈 화면 위젯을 바꿀 수 있습니다. 시간표 위젯을 숨기는 것과 저장된 시간표를 지우는 것은 다른 동작입니다. 홈에서 보이지 않을 때는 먼저 시간표 메뉴의 입력값과 위젯 표시 설정을 함께 확인하세요.
