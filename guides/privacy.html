기기에 저장하는 정보

오풍은 맞춤 표시를 위한 이름, 알레르기 번호, 좋아하는 음식, 위젯 구성, 시간표, D-DAY, 테마와 팝업 닫기 상태 등을 브라우저 저장소에 저장합니다. 게임에서 사용하는 기록·설정도 기기 저장소를 사용합니다. 이 값들을 계정 동기화를 위해 운영자 서버에 전송하는 기능은 제공하지 않습니다.

이름은 실명 대신 원하는 호칭을 입력할 수 있습니다. 기본 정보 확인에는 이름이나 알레르기 입력이 필수가 아닙니다. 공용 기기에서는 개인 설정을 남기는 데 유의해 주세요.

보관·삭제와 복원

설정값은 해당 브라우저에 남아 있다가 사용자가 기능의 삭제·초기화를 사용하거나 브라우저의 사이트 데이터 삭제 기능을 이용하면 제거됩니다. 전체 사이트 데이터를 지우면 시간표 등 필요한 기록도 사라질 수 있으므로 먼저 별도로 기록하세요.

서버 백업과 기기 간 자동 복원은 제공하지 않습니다. 브라우저 데이터 삭제, 비공개 모드 종료, 기기 변경 등으로 사라진 입력값을 운영자가 복원할 수 없습니다.

외부 정보 조회와 연결

사이트 파일은 GitHub Pages에서 제공됩니다. 급식 조회 시 NEIS, 날씨 조회 시 오풍이 사용하는 날씨 중계 서비스와 통신하며, 사용자가 지정한 날짜나 학교 식별값 등 조회에 필요한 정보가 전달됩니다. 웹 요청 과정에서 접속 IP·브라우저 정보 등이 호스팅·제공 기관에 전달될 수 있습니다.

일본 여행 지도는 외부 지도 라이브러리와 지도 타일 제공자를 이용하며, Google Maps 등 외부 링크를 누르면 해당 서비스로 이동합니다. 연결된 서비스의 개인정보 처리 방식은 각 제공자의 정책을 따릅니다.

광고·제휴 링크와 오류 신고

이 버전에서는 카카오 애드핏 광고 SDK와 광고 단위를 제거했습니다. 유심사 제휴 안내는 별도의 서비스이며, 제휴 링크를 통한 구매 시 운영자에게 수수료가 지급될 수 있다는 표시를 유지합니다.

오류 신고·운영 문의는 Google Forms로 연결됩니다. 사용자가 제출한 내용은 문제 확인과 응답을 위해 사용하며, 비밀번호나 불필요한 개인정보를 적지 마세요. 제출한 내용에 관한 정정·삭제 요청도 같은 문의 경로로 전달해 주세요.

문의와 변경 안내

서비스 운영자: 양혁준. 개인정보 관련 문의는 운영 문의 폼으로 전달할 수 있습니다. 저장 항목이나 외부 서비스가 바뀌면 이 안내를 수정하고 수정일을 표시합니다.
